# Calcolatrice Full-Stack

Calcolatrice con Node.js, Express e MongoDB.

## Prerequisiti
- [Node.js](https://nodejs.org)
- [MongoDB](https://www.mongodb.com/docs/manual/installation/)

## Installazione
1. Clona la repository
2. Installa le dipendenze:
npm install
3. Avvia MongoDB
4. Avvia il server:
npm start
5. Apri il browser su `http://localhost:3000`

## Funzionalità
- Operazioni aritmetiche: addizione, sottrazione, moltiplicazione, divisione, modulo
- Storico delle ultime 20 operazioni persistito su MongoDB
- Cancellazione della cronologia
